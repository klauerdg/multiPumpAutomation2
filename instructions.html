Multi-Pump Automation

User Guide  |  Northeastern University Daily Lab  |  Capstone 2026

Overview

This application controls up to 9 peristaltic pumps simultaneously from a Raspberry Pi touchscreen. Each pump can be configured independently for flow rate, run duration, and flow profile (constant or pulsatile), then started, paused, resumed, and stopped — individually or as a group.

The interface has two main pages:

Setup

Configure each pump's flow rate, duration, and waveform before a run. Save and load presets.

Run

Monitor and control live pump operation. View PPS, elapsed time, and per-pump status.

Hardware Layout

Nine pumps are split across two Arduino controllers. The application labels them Pump 1–9 on screen, which map to physical pump positions on your hardware rig. Ensure both Arduinos are connected via USB before launching the software.

Note If a pump does not respond, check that the correct serial ports are configured in backend.py (SERIAL_PORT_A and SERIAL_PORT_B).

Quick Start

  1. Launch the application (python3 main.py or double-click the launcher).
  2. On the Setup page, enter a flow rate for each pump you want to use.
  3. Tap Ready to Run in the toolbar — this transfers settings to the Run page.
  4. On the Run page, tap Start All to begin all pumps simultaneously.
  5. Monitor flow and status on each pump card. Use Pause All or Stop All as needed.
Tip Pump cards with a flow rate of 0 (or left blank) are automatically hidden on the Run page — only active pumps are shown.

Setup Page

The Setup page is where you configure every pump before starting a run. The toolbar at the top provides global controls; the nine pump cards below let you fine-tune each pump individually.

Pump Cards

Each pump card contains:

FieldDescription
Flow (µL/min)Target volumetric flow rate for this pump. Leave at 0 to exclude the pump from the run.
Duration (min)How long the pump runs. Leave blank or 0 for continuous (no time limit).
Select checkboxMarks this pump for group operations (Apply to Selected, Pause Selected, etc.).
Prime buttonRuns the pump at the prime flow rate for fast tube priming. Tap again to stop.

Group Flow

The Flow and Prime fields in the top toolbar apply values to all selected pump cards at once:

  • Enter a value in the Flow box, select the pumps you want, then tap Apply to Selected.
  • The Prime field sets the flow rate used when any pump's Prime button is pressed (default 15.00 µL/min).

Priming

Priming fills the tubing before a real run. Each pump card has a Prime toggle button. While priming:

  • The pump runs at the prime flow rate set in the toolbar.
  • Tap the button again to stop priming.
  • Priming automatically stops when you tap Ready to Run.
Important Do not tap Ready to Run while a pump is still actively priming — stop priming first to avoid carrying incorrect state into the run.

Advanced Settings

Tap Advanced in the toolbar to open the Advanced Settings dialog. This lets you set a non-constant flow profile for all selected pumps.

SettingDescription
ModeChoose Constant or Pulsatile (see Flow Modes).
Base FlowAverage or minimum flow rate (µL/min).
Max FlowPeak flow rate for pulsatile waveforms.
Period (s)Time for one complete waveform cycle (pulsatile only).
WaveformSquare wave or Sinusoidal (pulsatile only).
Total Time (min)Duration override for the selected pumps.
Flow StepIf enabled, the pump switches to a different flow rate after a set number of minutes into the run.

Tap Apply inside the dialog to save these settings to the selected pumps.

Presets

Presets save the complete configuration of all nine pumps (flow rates, durations, modes, waveform parameters) so you can restore them instantly.

  • Save Preset — enter a name and tap Save. The preset is stored on disk and persists across restarts.
  • Load Preset — pick a preset from the list. Tap Load to apply it to the Setup page, or Delete to remove it permanently.

Per-Pump Calibration

Tap Calibration to open the calibration dialog. This lets you enter a multiplier for each pump to compensate for mechanical wear or tubing variations. A value of 1.0 means no correction (default).

Note Calibration factors are purely a wear-offset multiplier applied on top of the standard 60 µL/min = 4000 PPS conversion. They do not change the base conversion rate.

Run Page

Navigate to the Run page by tapping Ready to Run on the Setup page. You will see a card for each active pump, a global timer, and a toolbar of run controls.

Run Card Display

Display itemMeaning
Flow (µL/min)Current target flow rate for this pump.
PPSPulse-per-second equivalent sent to the Arduino (60 µL/min = 4000 PPS).
Status lineShows Running, Paused, Step change, Pulsatile waveform info, or Run complete.
Select checkboxMarks this pump for selective pause/resume/start operations.

Starting Pumps

Start All

Starts every visible pump simultaneously. The button label switches to Stop All once clicked.

Start Selected

Starts only the pumps whose Select checkbox is ticked. Useful for staggered starts.

Pausing & Resuming

Pause All

Immediately stops all running pumps and freezes their individual timers.

Pause Selected

Pauses only the pumps whose Select checkbox is ticked.

Resume Selected

Restarts selected paused pumps, continuing from where they left off — including remaining duration.

Tip When you resume a pump running a pulsatile waveform, it picks up at the correct remaining duration — it does not restart the waveform from the beginning.

Stopping

  • Stop All (toolbar) — halts all pumps and marks them complete.
  • The Start All / Stop All toggle button at the top-left also stops everything once a run has begun.
  • After stopping, return to the Setup page and tap Ready to Run again to prepare a new run.

History Log

Tap History to open a scrollable log of run events — start, pause, resume, stop, and flow changes — timestamped for the current session. The log is cleared when the application is restarted.

Flow Modes

Constant Flow

The pump runs at a fixed flow rate (µL/min) for the entire duration. This is the default mode. Configure it by simply entering a flow rate on the pump card.

Pulsatile Flow

The pump alternates between a base (low) flow and a peak (high) flow on a repeating cycle — simulating physiological pulsatile conditions. Set via Advanced → Mode: Pulsatile.

WaveformBehaviour
SquareInstantaneously switches between base flow and peak flow every half-period.
SinusoidalSmoothly ramps between base and peak flow following a sine curve over each period.
Example Base: 10 µL/min, Max: 60 µL/min, Period: 2 s, Square wave → the pump runs at 10 µL/min for 1 s then 60 µL/min for 1 s, repeating continuously.

Flow Step

Available for any mode via Advanced Settings. After a specified number of minutes, the pump automatically switches to a different target flow rate. The step change is shown in the run card's status line.

Themes & Fun Mode

Open Settings (gear icon in the navigation bar) to change the visual theme. Built-in themes include light blue, dark, and high-contrast options. Tap Apply in the Settings dialog to activate the selected theme.

Fun Mode

Toggle Fun Mode in the Settings dialog to enable extra visual effects:

  • The toolbar cycles through rainbow colours.
  • Nyan Cat flies across the screen periodically, heading toward wherever you last touched the screen.
  • Clicking Nyan Cat unlocks the Rainbow theme.

Secret Themes

ThemeHow to unlockDescription

Tips & Troubleshooting

SymptomLikely cause & fix
Pump doesn't start after pressing Start All Check USB connections to both Arduinos. Verify serial ports in backend.py. Check the terminal for error messages.
PPS shown on run card seems wrong The displayed PPS uses 60 µL/min = 4000 PPS. If you've entered a per-pump calibration factor other than 1.0, the display includes that multiplier.
Pulsatile pump doesn't resume correctly Make sure you use Resume Selected, not Start Selected, after a pause. Resume restores remaining duration; Start would restart from the full duration.
Preset not saving Ensure the application has write permission to the directory. Check that the preset name field is not empty before tapping Save.
Background image not showing in Northeastern / Transparent theme Copy the appropriate JPG into UI/images/ on the Pi (see above). The app silently falls back to a solid colour if the file is missing.
Keyboard doesn't appear when tapping a text field The on-screen keyboard should appear automatically. If it doesn't, tap the field a second time. A physical USB keyboard can also be used.
All pumps show "Run complete" immediately Check that durations are set correctly. A duration of 0 means continuous (no limit); very small values (e.g. 0.01 min) will complete almost instantly.
