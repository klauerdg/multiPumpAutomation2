Sound files for Fun Mode
========================
Place the following WAV files in this directory:

  pump_start.wav   — short pump/bubbling sound, played when a pump starts or priming begins
  complete.wav     — celebration / "yay!" sound, played when all automation finishes
  nyan.wav         — Nyan Cat theme (optional), loops while Nyan Cat is on screen

WAV format recommended (PCM, 44.1 kHz, stereo or mono).
MP3 also works if your Qt Multimedia backend supports it.

Free sound suggestions:
  - pump_start: a bubbling or motor-rev sound (freesound.org)
  - complete:   a fanfare or cheer clip (freesound.org)
  - nyan:       the Nyan Cat song is widely available online
